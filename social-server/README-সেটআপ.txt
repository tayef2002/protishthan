ফেসবুক পেজে নিজে নিজে পোস্ট (Supabase সার্ভার)
================================================

কীভাবে কাজ করে
- কার্ডের ছবি আর ক্যাপশন আপনার পিসির ফোল্ডারে থাকে।
- `node social_queue.js` সেগুলো নতুন Supabase প্রজেক্টে তুলে দেয় আর প্রতিটার সময় ঠিক করে।
- Supabase প্রতি মিনিটে দেখে কিছু পোস্টের সময় হয়েছে কিনা। হলে ফেসবুকে পোস্ট করে দেয় (পিসি বন্ধ থাকলেও)।
- ছবির সাথে নাম মেলানো ক্যাপশন (`নাম.txt`) আর প্রথম কমেন্ট (`নাম.comment.txt`) দেওয়া যায়, দুটোই ঐচ্ছিক।

সব গোপন জিনিস (টোকেন, চাবি) থাকে শুধু আপনার পিসির `.env` ফাইলে আর Supabase-এর Secrets-এ।
এগুলো কখনো চ্যাটে বা গিটে দেবেন না।

ধাপ ১: নতুন Supabase প্রজেক্ট (আপনি করবেন)
- supabase.com এ নতুন প্রজেক্ট খুলুন, নাম: protishthan-social। মূল সাইটের প্রজেক্ট থেকে আলাদা রাখুন।
- রিজিয়ন: Singapore। ডাটাবেস পাসওয়ার্ড কোথাও লিখে রাখুন।
- প্রজেক্ট তৈরি হলে Project Settings > API থেকে "Project URL" দেখুন। এটা গোপন নয়, আমাকে দিতে পারেন।

ধাপ ২: টেবিল বানানো (আপনি করবেন, ১ মিনিট)
- Supabase এর SQL Editor খুলে `01_schema.sql` ফাইলের পুরো লেখা পেস্ট করে Run করুন।
- pg_cron বা pg_net নিয়ে ভুল এলে Database > Extensions এ গিয়ে দুটো চালু করে আবার Run করুন।

ধাপ ৩: স্থানীয় সেটআপ (আমি বা আপনি)
- এই ফোল্ডারে `node social_setup.js` চালান। এটা `.env` ফাইল বানায়।
- `.env` খুলে SUPABASE_URL আর SUPABASE_SERVICE_KEY নিজে বসান (চাবিটা Project Settings > API > service_role)।
- আবার `node social_setup.js` চালান। এবার `02_cron_SECRET.sql` তৈরি হবে।
- ওই ফাইলের লেখা SQL Editor এ Run করুন (প্রতি মিনিটের কাজ চালু হয়)।

ধাপ ৪: ফাংশন বসানো (আপনি করবেন)
- Supabase এ Edge Functions > Deploy a new function > Via Editor। নাম দিন: publish-due
- `functions/publish-due/index.ts` ফাইলের পুরো লেখা পেস্ট করুন।
- "Verify JWT" বন্ধ করুন (আমরা নিজেদের গোপন শব্দ দিয়ে পাহারা দিই)। Deploy করুন।
- Edge Functions > Secrets এ দুটো যোগ করুন:
    CRON_SECRET  = .env ফাইলের CRON_SECRET= এর পরের লেখাটা
    FB_PAGES     = নিচের ধাপ ৫-এর JSON

ধাপ ৫: ফেসবুকের চাবি (আপনি করবেন, নিজের অ্যাকাউন্টে ঢুকে)
(Meta মাঝে মাঝে মেনুর নাম বদলায়। আটকে গেলে স্ক্রিনশট দিন, তবে চাবি ঢেকে।)
1. developers.facebook.com এ ঢুকে নতুন অ্যাপ বানান (নিজেই অ্যাডমিন)।
2. Tools > Graph API Explorer: আপনার অ্যাপ বেছে "Get User Access Token" চাপুন। অনুমতি নিন:
   pages_show_list, pages_read_engagement, pages_manage_posts, pages_manage_engagement
3. ওই টোকেনকে দীর্ঘ-মেয়াদি করুন (অ্যাপ সেটিংসের App ID আর App Secret লাগে):
   GET /oauth/access_token?grant_type=fb_exchange_token&client_id=APP_ID&client_secret=APP_SECRET&fb_exchange_token=ছোট_টোকেন
4. দীর্ঘ-মেয়াদি টোকেন দিয়ে GET /me/accounts চালান। প্রতিটা পেজের id আর access_token আসবে।
   এই পেজ-টোকেনের মেয়াদ সাধারণত শেষ হয় না। পাসওয়ার্ড বদলালে বা অ্যাডমিন থেকে বাদ পড়লে বাতিল হয়।
5. FB_PAGES এর মান এভাবে লিখুন (main = পেজের ডাকনাম, যা social_queue এর --page= এ দেবেন):
   {"main":{"page_id":"পেজের_id","token":"পেজ_টোকেন"}}
   তিনটা পেজ হলে কমা দিয়ে আরও দুটো যোগ করুন।
6. App Secret আর টোকেন কোথাও লিখে রাখবেন না, শুধু Supabase Secrets এ।
- যদি Meta স্থায়ীভাবে চালাতে অ্যাপ রিভিউ চায় (pages_manage_posts), সেটা আলাদা ঝামেলা। সেটআপ চলাকালেই বোঝা যাবে।

ধাপ ৬: পরীক্ষা
- `node social_status.js --check` : প্রতিটা পেজের টোকেন ঠিক আছে কিনা বলে দেয়।
- একটা ছবি ১০ মিনিট পরের সময়ে লাইনে দিয়ে দেখুন:
    node social_queue.js --dir=<ফোল্ডার> --page=main --start=YYYY-MM-DD --slots=HH:MM --go
- `node social_status.js` : কী অপেক্ষায়, কী পোস্ট হয়েছে, কী ব্যর্থ হয়েছে দেখায়।

প্রতিদিনের ব্যবহার
- আগে নমুনা দেখুন:  node social_queue.js --dir=<ফোল্ডার> --page=main --start=2026-11-10 --slots=08:00,13:00,18:00,22:00
- ঠিক থাকলে শেষে --go যোগ করুন। একই ছবি দুইবার লাইনে যাবে না (ফোল্ডারে .queued.json থাকে)।
- ফেসবুক ৩০ দিনের বেশি আগে নির্ধারণ নেয়, আমরা সময়টা নিজেরা ধরে রাখি তাই সীমা নেই, তবে অত আগে লাইনে না দেওয়াই ভালো।

নিরাপত্তা
- fb_posts আর social_config টেবিলে বাইরের কারো ঢোকার পথ বন্ধ।
- ফাংশন গোপন শব্দ (CRON_SECRET) ছাড়া কাউকে উত্তর দেয় না।
- ব্যর্থ পোস্ট ৩ বার পর্যন্ত চেষ্টা হয়। টোকেন বাতিল হলে সাথে সাথে "ব্যর্থ" দেখায়। চেষ্টা চলে না।
- পোস্ট হয়ে গেলে আর কখনো একই ছবি আবার যায় না। কমেন্ট ব্যর্থ হলেও না।
- "চলছে" অবস্থায় ২০ মিনিটের বেশি আটকে থাকলে "ব্যর্থ" দেখায়, নিজে আর চেষ্টা করে না, কারণ ততক্ষণে হয়তো পোস্ট হয়েই গেছে। ফেসবুক পেজে দেখে নিন।
